    Cómo se usa
    
    
    
      
    Termostato: SET abre el menú de estado (SEt consigna, Pb1, Pb2, CC ciclo continuo, AL alarmas): SET para ver o cambiar, ▲▼ para moverse, ⏻ para salir. Mantén SET para los parámetros (nivel usuario; con la contraseña PA = 22, nivel instalador con carpetas). ▲ / ▼ muestran máxima y mínima; mantener ▲ = desescarche, mantener ▼ = reset. ⏻ enciende la luz; mantener ⏻ = espera. El botón de puerta simula el contacto de puerta.
    
      
    Central: F1 compresores/ventiladores, F2 consignas, F3 alarmas (mantener: lista). Mantén OK para el MENÚ: diagnóstico (alarmas, entradas/salidas), servicio, reloj y franjas, funciones, parámetros (contraseña 123) y USB. En la tabla de compresores puedes poner cada uno en automático o fuera de servicio.
    
      
    Esquema: las presiones son relativas, como en los manómetros. Los círculos en la tubería son los puntos de medida. Las tuberías que se cruzan sin conectarse saltan con un pequeño arco.
